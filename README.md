# 🛡️ Systems, Security & Automation Portfolio

A clean, single-page professional portfolio and service landing page designed to highlight technical offerings in cybersecurity, system hardening, and automation. 

## 🚀 Overview

This repository contains the source code for my personal landing page. It serves as a digital business card and a centralized hub for clients to request security audits, patch management, or custom script development. 

The design is minimalist, utilizing a purple and green color palette, and features a "Blue Team" terminal aesthetic to reflect a defensive cybersecurity focus.

## 🛠️ Tech Stack

This project is built to be lightweight, fast, and easy to deploy with zero build steps required.

*   **HTML5:** Semantic and accessible structure.
*   **Tailwind CSS:** Utility-first styling (implemented via CDN for simplicity).
*   **Fonts:** Google Fonts (*Plus Jakarta Sans* for readable prose, *JetBrains Mono* for terminal/code aesthetics).

## 🗂️ Features

*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop viewing.
*   **Dedicated Cybersecurity Section:** Highlights vulnerability audits, SIEM setup, and website penetration testing.
*   **Services Grid:** Clean layout detailing patching workflows, custom scripting, and infrastructure support.
*   **Frictionless Contact:** Quick-copy email integration for immediate client outreach.

## 💻 Local Development

Since this project uses the Tailwind CSS CDN, there are no dependencies to install or build processes to run.
